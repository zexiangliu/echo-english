# Echo · 配音与唱歌练习

把喜欢的 YouTube 对白和歌曲，变成自己的声音。支持英语、中文、日语、韩语等原文字幕的逐句配音、跟读、伴奏录唱与回听。普通配音无需后端或 API Key；可选的去原唱伴奏、电影背景音提取共用同一个本机服务。

听原曲／原声时，可点击主区歌词、上下句或歌词列表跳到句首，暂停时点击也会继续播放；整首内跳转保留整首范围，片段模式切换到所点击的句子。也可在播放进度附近勾选「循环播放当前范围」，随时取消。录音或前置准备期间，底部「重新录制」会丢弃当前未保存的尝试，并按当前范围重新进入前置准备；已保存版本保留。

在「合成整首」中可选择「自定义起止时间」，输入起点、终点秒数，仅试听或导出这一段。版本选择、人声对齐及回听音量比例照常应用；混合导出只需覆盖该区间的伴奏，文件名包含实际起止时间。

录唱中，进度条上方提供「跳过前奏／跳过间奏」：按带时间轴的歌词定位下一句，当前歌词仍在演唱时禁用。跳过开头未进入歌词的录音会丢弃；已唱过的部分先保存成独立片段，之后从下一句以 1× 继续录唱，合成时保持原视频时间轴。跳转到下一句前 N 秒作准备，N 取自练习设置中的前置时长，最早从视频开头播放；准备段不录入人声，正式录音从歌词起点开始；字幕时间不准时需先微调字幕。

## 练习准备、收藏与迁移

主界面保留底部固定操作区和「练习设置／伴奏（背景音）／录音设置」工具栏，以及「练习 / 台词（歌词）/ 录音」三个页面。设置向导与麦克风试音合并在顶部页签右侧的「练习准备」入口：

- **帮我设置**：首次使用时顶部入口显示「帮我设置」。选择唱歌／配音、耳机／外放及可选的文件用途，先查看推荐的回声消除、自动增益、耳返和音质，再显式应用；可在结果页撤销。保留各模式的录音范围、伴奏选项、前置播放、录音、字幕、输入设备和手动增益数值。耳返默认关闭，戴耳机时可选开启；外放关闭耳返。日常练习使用高品质压缩，后期制作可选无损 PCM（需浏览器支持）。麦克风试音直接使用下方区域。
- **伴奏与背景音**：底部「生成伴奏／生成背景音」为统一入口，当前范围准备好后显示「调整伴奏／调整背景音」，打开即可生成、试听并调整监听音量。顶部显示服务连接、模型准备状态和安装说明，可直接管理与下载模型；「模型与音质」进入次级偏好页，返回后保留生成范围。生成和试听无需预先开启录音播放；录制时播放原曲、伴奏或静音仍在「练习设置」选择。
- **麦克风试音**：以当前录音设置试录最多 10 秒，显示实时音量，结束后可回听；点击「调整麦克风」进入设备与录音设置。试音前暂停视频，关闭弹窗即释放麦克风并丢弃试音，不占练习库空间。耳返开启时请戴耳机。
- **收藏**：收藏当前视频。在「练习库 → 收藏」查找、打开或取消收藏；收藏独立于录音和缓存清理。
- **备份与迁移**：「练习库 → 备份与迁移」可导出全部练习或单个视频的 `.echo` 包，包含字幕、进度、所有录音版本、收藏与合成选择，伴奏／背景音可选。音频按原始字节保留，不重新压缩。在另一台电脑安装 Echo 后，选择练习包，检查数量并合并导入。默认保留现有进度，同 ID 音频与收藏跳过；可明确勾选覆盖同视频进度。导入一次事务完成，空间不足时不会只写入部分内容。导入的音频额外保留，不受自动版本／缓存数量上限淘汰，仍可手动清理。麦克风设置和本机服务模型不随包迁移，需在新电脑重新选择或安装。练习包包含自己的录音，请自行保管。

快捷键在面板打开、光标不在输入框且没有弹窗时生效；按物理键位识别，Mac 使用 **Option + Shift**，Windows / Linux 使用 **Alt + Shift**。说明也在「练习准备」弹窗底部。

| 组合键（加上述修饰键） | 操作 |
| --- | --- |
| R | 开始／结束录音 |
| O | 听原声／原曲 |
| P | 回放当前录音 |
| ← / → | 上一句／下一句 |
| C | 对比原声与当前录音（依次播放） |
| / | 打开快捷键说明 |

录音过程中再次按 **R** 组合键结束录音；录音页的回放和对比针对当前选中版本，没有可用录音时不触发。收藏、音量、增益和语言使用界面操作，不分配快捷键。

**Esc** 停止当前操作或关闭当前弹窗；在面板内空闲时可关闭面板。输入框、字幕搜索、输入法组合输入及其他弹窗中的按键不会触发上述组合键。浏览器或系统占用的组合键可能无法传给插件，可直接使用界面按钮。

准备与自动练习、麦克风与音质、语言与字幕、伴奏与背景音集中在一个带分类分页的设置弹窗中。底部固定工具栏的「练习设置／伴奏（背景音）／录音设置」、台词页的「语言与字幕设置」可直达对应分类；底部「伴奏／背景音」直接打开生成与试听页，台词卡片的「调整语言」和试音页的「调整麦克风」也指向同一弹窗。设置自动保存，关闭后回到原页面；模式、范围、选句和时间微调入口保持直接可见；速度、播放／录音和设置工具栏固定在底部，无需滚动寻找。时间按钮直接打开独立的片段起止时间小弹窗，可输入秒数、±0.2 秒微调或取当前播放位置，修改自动保存，收藏改为标题栏星标。歌词卡片随面板高度展开，空间充足时放大当前句，只保留上一句，并按可用高度显示后续多句（最多 5 句），其中下一句放大突出，紧凑时突出当前歌词，播放／录音时恢复上下句提示；录音中的伴奏和耳返音量仍就近显示。前置播放、循环次数与自动练习在「准备与自动练习」中设置，启动循环／自动练习后返回主界面。生成页只显示生成范围、生成／试听、就绪状态与进度，可选「整首歌曲／整段视频」「当前练习范围」「自定义段落」或「自定义时间区间」；自定义段落用起句、止句选择至少两句连续字幕，无字幕时可改用时间区间。范围独立于录音选段，每次最长 10 分钟；较长视频请分段准备。整首音频可被较短练习范围复用，已有覆盖所选范围的音频时直接试听，无需重复生成。监听音量位于伴奏页，可边试听边调整；录音参考音在「练习设置」选择。服务说明和模型安装状态直接显示在伴奏页，模型选择与保存音质通过「模型与音质」进入，返回后保留生成范围。麦克风设置按输入与音质、录入人声、耳机监听分组。生成时留在生成页查看阶段进度，也可停止；关闭弹窗后主界面继续显示任务进度。试听时可在当前页调音量或停止。

确认视频没有可读取字幕时，主区与字幕页会显示「自动载入字幕不可用」，不再反复等待文字记录。可导入 SRT／VTT、手动选时间范围练习，或点击「重新检测字幕」。网络请求失败会单独提示；已有字幕与录音保留。

## 制作与编辑歌词／字幕

在「台词／歌词」页，无字幕时点击 **粘贴歌词／粘贴文本**，已有字幕时点击列表标题旁的 **编辑歌词／编辑字幕**。读取视频字幕与导入文件在上方，语言与字幕来源在标题右侧。无字幕视频的主区也提供「粘贴歌词制作字幕」。这是独立宽版弹窗，直接控制当前 YouTube 原视频，无需伴奏服务或额外模型。

无字幕时默认使用 **粘贴歌词并标时**，全部操作使用鼠标：

1. 粘贴完整歌词，**每行一句**，空行忽略，点击「完成粘贴，开始标时」。列表显示所有待标时歌词，顶部显示下一行。
2. 点击播放；听到这一行开始时点击 **标记开始**，结束时点击 **标记结束**。一对标记对应一行歌词，自动填入，播放不中断。上一句终点自动作为下一句默认起点，连续歌词可直接点击「标记结束」；需要留出间奏时，点击「标记开始」覆盖默认起点。最后一句完成后即可保存。
3. 点击已标时的歌词或时间轴区间，直接播放对应部分，到终点自动停止；可开启循环试听。未标时歌词标红，多出的空区间标黄。补齐或删除多余区间后才能导出／载入；未完成的开始标记可以取消。
4. 标错某句时，点击该句后选择 **清空时间，重新标记**，只清除此句的时间，歌词和其他句子的时间保留。补标后自动跳到下一句未标时的歌词，跳过中间已标好的句子；目标句前一句已有终点时，同时跳到该位置继续标时，并将其作为默认起点。此操作支持撤销和草稿恢复。
5. 鼠标放在右侧起点／终点数字上，滚轮向上加 0.5 秒、向下减 0.5 秒。起点从新位置向后试听最多 3 秒；终点从前面最多 3 秒播放到新终点，均限制在当前句内。连续滚动后只试听最终位置。也可拖动时间轴区间两端微调，或在右侧输入秒数、`分:秒.毫秒`／`时:分:秒.毫秒`。已相接的相邻边界可联动，原有间隔保留。两句时间重叠时，右侧显示「终点设为下句起点」，可一键缩短当前句，下一句保持不变。顶部「修复全部重叠」可批量处理，跳过固定终点或起点过近的句子并提示；整批修正可一次撤销。调整支持撤销／重做。
6. 点击 **保存并载入主界面**，或导出 SRT／VTT。

已有字幕默认进入 **微调已有字幕**，共用同一套点击试听、边界拖动和数字微调。右侧可修改文字并点击应用（换行拆句），或点击「与下一句合并」。顶部可切换到歌词标时流程。编辑器不提供自定义键盘快捷键。

已有录音和录制范围保留；普通微调保留句子标识，合并／拆分生成新标识，不静默重写旧录音。

编辑器自动将草稿保存到本机，关闭时不自动替换主界面字幕。草稿单独存储，不会被练习进度保存覆盖；迁移前请保存并载入或导出字幕，未应用的草稿暂不包含在练习包中。单次最多 2000 句、20 万字；保存失败会明确提示，仍可导出。

编辑器按需初始化，歌词列表仅渲染可见行，时间轴仅渲染当前时间窗口；播放时只更新播放位置与高亮。关闭后移除播放监听、动画和大列表／撤销历史，不在录音、耳返或回听链路中处理编辑数据。

## 选择分离模型

唱歌或配音时，点击底部「伴奏／背景音」，先查看服务与模型准备状态，再进入「模型与音质」选择模型：

- **Demucs（默认）**：歌曲伴奏推荐，也可提取电影背景音，首次下载约 80 MiB。
- **BandIt v2 多语言（可选）**：电影配音使用，去除对白并保留音乐、音效；额外权重约 426 MiB、独立依赖约 380 MiB，建议另留 2 GiB 空间。CPU 可运行，但明显慢于 Demucs；可用 NVIDIA CUDA，Mac 暂用 CPU。

选择尚未安装的模型后，点击「安装并提取背景音」即可。也可打开独立的「管理模型」弹窗安装、停止、重试或删除权重；已有音频与录音保留。下载支持续传及 SHA-256 校验，安装过程使用现有的单一进度区。模型安装需要先启动本机服务；从旧版升级时请重启服务并重新加载扩展、刷新 YouTube。

BandIt 权重采用 CC BY-SA 4.0，代码 Apache 2.0；模型来源、缓存路径和限制见 [本机服务说明](karaoke/README.md)。

在同一设置中可选「伴奏／背景音音质」：默认 **标准 · MP3（192 kbps）**，或 **无损 · FLAC（24 位）**。无损文件更大，避免分离后再次做 MP3 有损编码；只对新提取生效，旧 MP3 不会变成无损。切换音质后会使用独立缓存，旧录音仍匹配录制时的背景音。

## 所需配置

**不需要独立显卡。** 插件的字幕、配音、录音、回听和导出在 Chrome 中运行；本机伴奏／背景音分离支持 CPU，以及安装 CUDA 版 PyTorch 后的 NVIDIA GPU 加速。Demucs 在 Apple 芯片 Mac 上支持 MPS 加速，自动检测可用性，失败可回退 CPU；已完成原生 Mac GPU 分离验证，具体速度取决于机型和素材。

| 项目 | 仅使用插件：字幕、配音、录音、回听 | 额外提取伴奏／电影背景音 |
| --- | --- | --- |
| 电脑 | 能流畅播放 YouTube 的电脑，无需独立显卡 | 多核 CPU，使用两个 CPU 线程；NVIDIA CUDA / Apple MPS 加速可选；本机已验证 RTX 3060 Laptop 6 GB |
| 内存 | 建议整机 8 GB 或以上 | 建议整机 8 GB 起步，16 GB 更宽裕，尤其同时打开多个浏览器标签页时 |
| 磁盘 | 按录音数量预留空间；无损录音和合成文件更大 | 建议至少预留 5 GB，供 Python 环境、工具、模型、处理中间文件与伴奏缓存使用；长期录音需另留空间 |
| 系统 | Windows / macOS / Linux 上的新版桌面 Chrome | Linux x86_64、macOS Intel / Apple 芯片、Windows x64；macOS 15 双架构自动验证通过；Windows 待实机验证 |
| 软件 | 仅需 Chrome，不需要 Python、Node.js 或 API Key | Python 3.10–3.12、FFmpeg（含 ffprobe）、Node.js 22+ 或 Deno；安装方式见下方 |
| 音频设备 | 录音需要麦克风及浏览器、系统权限；建议戴耳机 | 同左；戴耳机可减少伴奏被麦克风收进去 |
| 网络 | 观看 YouTube、读取在线字幕及查词需要联网；已缓存录音可本地回听 | 首次安装、首次下载模型及提取 YouTube 音频需要联网；已有伴奏可直接回听和录唱 |

内存与磁盘数值是建议起点，**不是实测最低配置**。长录音、无损格式和整首合成会增加资源占用。录音保存在浏览器，伴奏在浏览器与本机服务各有缓存；插件的缓存管理只清理浏览器副本，本机服务缓存位置见下方说明。

伴奏生成不是实时处理。已有 Linux CPU 测量：i7-1165G7 / 16 GB 内存，15 秒音乐片段约处理 35 秒，分离进程内存峰值约 1.5 GiB。另一次同素材对比：i7-11800H 处理约 20 秒电影片段需 30.89 秒，RTX 3060 Laptop 需 5.06 秒（均含载入和写出，不含下载）。短片段结果不代表整首歌曲或其他电脑的速度；当前单次最长 10 分钟。Linux / Windows 默认安装 CPU 依赖，NVIDIA GPU 需额外安装，步骤见 [CUDA 加速](karaoke/README.md#可选nvidia-gpu-加速)；Apple GPU 使用 Mac 标准依赖即可，见 [MPS 加速](karaoke/README.md#apple-芯片-macmps-加速)。

各系统安装与验证状态见 [跨平台适配](PLATFORM_SUPPORT.md)，伴奏依赖与缓存位置见 [伴奏安装与使用](karaoke/README.md)。

## 安装

从 GitHub 仓库选择 **Code → Download ZIP** 并解压，或使用 Git 克隆仓库。加载时选择解压目录中的 `extension/` 文件夹，不是整个仓库。

1. 在 Chrome 地址栏打开 `chrome://extensions`。
2. 打开右上角「开发者模式」，点击「加载已解压的扩展程序」。
3. 选择本项目下的 `extension` 文件夹。
4. 打开或刷新一个 YouTube 视频播放页，点击工具栏的 Echo 插件图标打开面板（可先在扩展程序菜单里固定图标）。

修改代码后，在扩展程序页面点重新加载，再刷新 YouTube 页面。

### 可选：一键安装并启动伴奏服务

普通配音、跟读、录音和回放只需要 Echo 扩展。「生成伴奏」或「提取背景音」还需要在运行 Chrome 的同一台电脑上启动本机服务；安装扩展不会自动安装这些依赖。

打开终端，进入解压或克隆后的项目根目录，运行：

```bash
bash start-karaoke.sh
```

首次会检查 Python 3.10–3.12、FFmpeg 和 JS 运行时，创建项目独立环境并安装依赖，然后启动服务。以后仍运行同一命令，会复用已安装环境；安装失败后可修复错误并重新运行。首次安装需联网，依赖可能占约 1–2 GB；约 80 MB 的分离模型在首次生成伴奏时下载。

- **Linux x86_64**：支持；缺少系统组件时通过 apt 安装，可能要求管理员密码。其他发行版需自行配置 Python / FFmpeg。
- **macOS Intel / Apple 芯片**：已提供脚本安装路径，尚待实机验证；缺少系统组件时需要已安装 Homebrew。
- **Windows x64**：已提供 PowerShell 安装启动入口，尚待实机验证。先安装 x64 Python 3.10–3.12、FFmpeg 和 Node.js 22+ 或 Deno，再运行下方命令。

保持终端开启，按 `Ctrl+C` 停止。回到插件切换「歌曲 · 演唱练习」，查看服务状态；已打开面板时可点击「重新检测」。连接成功后生成伴奏，再试听和录唱。未连接时会展开启动说明。服务只监听 `127.0.0.1:8765`；已有的浏览器伴奏缓存和录音回放不要求服务在线。

Windows 在 PowerShell 中运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\start-karaoke.ps1
```

两个脚本均可从任意目录调用完整路径，自动创建本机专用 `.venv`；不要跨机器复制虚拟环境。Intel Mac 自动选择 PyTorch 2.2.2，其他目标平台使用 2.5.1。

完整配置见 [伴奏安装与使用](karaoke/README.md)；实机验证步骤与当地 agent 交接见 [跨平台适配](PLATFORM_SUPPORT.md)。

## 使用

配音和唱歌均支持三种录音范围：整段视频（唱歌时为整首歌曲）、当前片段、段落（多句）。范围选择直接显示在练习主区，听原声、录音、循环和自动练习共用所选范围。整段与段落最长 10 分钟；段落需要至少两句时间轴字幕，连续录下选定多句及句间空隙。整段和段落不自动跳下一句，片段模式可以开启。配音与唱歌按视频分别记住范围选择；旧版配音练习继续使用当前片段。

「当前片段」可通过主区的下拉框直接选句，自动更新起止时间；修改时间后显示为自定义范围。配音模式也支持下拉选句。歌词卡片上的「调整语言」跳到台词／歌词页并展开语言与字幕设置。

配音和唱歌共用底部的「听原声 / 回听 / 录音」主操作，按钮按模式调整名称。歌词准备统一在台词／歌词页读取或导入；没有字幕时，练习页提供「准备字幕」快捷入口。录音页集中管理版本、回放、下载与合成；所选版本的删除位于录音卡片上，列表快捷删除和撤销保留。

顶部按活动切换「对白 · 配音跟读」和「歌曲 · 演唱练习」。说对白适用于访谈、影视、动漫等，直接录制麦克风；唱歌曲复用本机伴奏生成和混音录唱。配音与唱歌分别记住录音参考音，按视频保存。内容语言在「台词 / 歌词 → 语言与字幕显示」中选择，默认根据文本建议，可手动更正。

「练习设置 → 录音时的参考音」可选择原曲／原声、伴奏／背景音，或不播放。选择原曲无需先提取伴奏，沿用 YouTube 音量；选择伴奏需先准备当前练习范围的音频。三种方式都只保存麦克风人声，建议戴耳机。录音回听和混合导出仍使用提取的伴奏／背景音，不会将原曲混入文件；也可先跟原曲录音，之后再提取伴奏用于合成。生成伴奏不会覆盖已选的原曲参考音。

「麦克风与录音设置」可选择系统默认、USB 或耳机等输入设备。首次点击「授权并检测」显示设备名称；检测后立即释放麦克风。选择在配音与唱歌间共用并记住，下次录音生效；设备拔出时保留选择并提示，不会自动换用其他麦克风。

可选「录音时听到自己（耳返）」，默认关闭。耳返使用低延迟采集请求和 Web Audio 直连链路，与手动增益共用处理图；准备阶段、暂停和结束时静音。耳返延迟默认选择「更低延迟（推荐）」，向浏览器请求最小输出缓冲。已保存的模式选择保持不变；若爆音或断续，可切回「标准（兼容）」，下次录音生效。浏览器可能为两种模式采用相同的实际缓冲。录音时显示输入、图缓冲及输出的浏览器估计，未报告的项保留未知，不相加为完整往返延迟；这些信息也保存在录音详情。设置里可调整耳返音量，录音时音量条下也可直接调整，0% 即静音；不改变录音或下载的音量。建议使用有线耳机，实际往返延迟由浏览器、声卡和耳机决定，不保证零延迟；已有声卡硬件直通监听时可关闭插件耳返，避免叠声。

录音时选择伴奏／背景音后，可在「麦克风 · 实时音量」下方直接调整伴奏／背景音监听音量（0–200%），准备阶段也可调整。与伴奏设置里的音量同步并按视频记住，只改变耳机监听，不影响录下的人声或回听音量比例。

耳返与回声消除或自动增益同时开启时，耳返开关下方会显示提示。点击「使用耳机推荐设置」可关闭当前配音／唱歌模式的这两项处理并记住选择，下次录音生效；另一模式的设置和原来的手动增益值保留。

1. 在面板底部搜索视频，或直接打开喜欢的视频。优先选择带目标语言字幕或时间轴歌词的视频。
2. 点击「读取台词」，插件会尝试展开视频简介、打开文字记录，并等待台词加载；也可以导入 SRT / VTT 字幕。
3. 选择一句台词，或在视频播放时标记起点、终点。每段最多 10 分钟。试听可选 0.5×–1.5×，每 0.1× 一档，另保留 0.75× 和 1.25×；前置准备与正式录音固定 1× 原速。
4. 点击「听原声」，再点击「开始配音」，首次使用需允许麦克风权限。
5. 配音时视频静音并继续播放，到终点自动停止，也可手动停止。
6. 点击「我的配音 + 画面」随视频回放，或点击「原声 / 配音」依次听两种版本。
7. 可隐藏台词练习脱稿，也可下载 WebM 录音。

下载文件按「视频标题＋片段起止时间＋音频类型」命名，例如 `晴天_00m50.0s-01m05.0s_人声.webm`。人声＋伴奏及整首合成 WAV 使用同一命名规则，整首文件另标「整首合成」。保留各语言标题，自动替换文件名不支持的字符；标题无法读取时回退到视频 ID。

唱歌的录唱范围支持「整首歌曲 / 当前片段 / 段落（多句）」。段落模式需要至少两句时间轴歌词，通过起句和止句选择连续多句，连同句间间隔一次录下；听原曲、伴奏生成、前置播放、循环和自动练习均沿用该范围，选择按视频保存。段落可与单句录音混合合成整首：按原视频时间轴放置，重叠处默认采用最新录音，未录处保留空白，不压缩时间。在「录音 → 分段合成整首 → 选择片段并合成」打开独立拼接界面，逐段试听、勾选是否导出、切换其他版本，并试听整首。试听与下载使用同一份选择、内容类型及打开界面时的回听音量比例；修改选择会停止旧试听。选择按视频保存在本地，恢复自动选择可重新采用最新版本。合成整首仍需 1× 录唱；混合下载需覆盖整首的伴奏。

片段的「前置播放」可在「练习 → 准备与自动练习」选择关闭（默认）、前 N 秒（0–30，初始 3 秒）或上一句，按视频保存。选择上一句时从上一句开头播放到当前片段起点，需要时间轴字幕；没有上一句则直接开始。例如片段为 50–60 秒，设为 3 后先听 47–50 秒原声，再开始片段录音；录音与下载仍为 50–60 秒。前置播放开始时即进入录音布局并显示麦克风实时音量，状态栏提示准备倒计时；到片段起点才正式录音，准备期间可点击「取消准备」，不保存录音。前置播放按视频时间计算，慢速时实际准备更久；起点不足时从视频开头播放。听原声、循环和自动练习也应用此设置，回听与原声对比保持录音范围。

「麦克风与录音设置」中的「录音音质」可选高品质压缩（默认，Opus 编码目标 256 kbps）或无损 PCM，选择在本机记忆，配音和唱歌共用，仅影响新录音。无损通过 Chrome 原生 PCM 录制，不经过 Opus；原始文件仍为 WebM，体积明显更大，部分外部播放器可能不支持。当前浏览器不支持 PCM 时会提示改选高品质压缩，不会自动降级。无损指编码阶段不压缩，麦克风、系统音效、回声消除、自动增益和手动增益仍会影响声音。

「录音 → 下载与录音详情」显示该条新录音的实际格式、压缩编码目标码率、麦克风及编码输入的采样率和声道数，以及浏览器报告的回声消除、降噪和自动增益状态；未报告的状态标为未知。旧录音没有这些参数。PCM 不显示浏览器返回的默认压缩码率。现有混合、整首合成 WAV 仍为 44.1 kHz / 16 位双声道，经过混音和格式转换，不承诺与原始 PCM 逐样本相同；旧 Opus 录音转成 WAV 也不能恢复已丢失的细节。

在「练习 → 麦克风与录音设置」可分别开关回声消除和自动增益，两项均为配音默认开启、唱歌默认关闭，按模式分别记住选择。外放时可尝试回声消除；人声偏小时可尝试自动增益，但唱歌可能出现音量起伏。调整从下次录音生效，实际处理效果取决于浏览器和设备；唱歌始终关闭降噪。关闭自动增益时可调整「手动录音增益」（0–24 dB，默认 0），固定放大新录音，回听与下载均生效，按模式记忆；建议从 +6 dB 开始，留意过载提示。手动增益不叠加到自动增益上，也会放大背景噪声，旧录音不受影响。

录音页上方先选择片段；点击片段或版本只做选择，不自动播放。选中录音的版本切换、回放、原声对比、调整与下载集中在底部固定操作区，与回听音量相邻。「调整与详情」弹窗集中人声对齐、结尾淡出、波形、采集参数和删除版本，弹窗底部固定显示进度条、回听音量和「试听调整效果」按钮，滚动时也能跳转、调音量或停止，播放中可边听边调。主界面与弹窗共用同一组播放控制，打开或关闭弹窗不会重启录音回放。对齐、淡出按版本保存；混响入口明确标注为本视频全局设置。点击「下载」进入独立下载页，选择原始文件、处理后人声或加伴奏／背景音；顶部「声音效果」旁的「合成整首」按钮直接打开片段选择与拼接界面，覆盖情况和导出说明集中在弹窗内。拼接页顶部的横向概览可点击，直接滚动下方列表到对应区间并短暂高亮，空白区间也可定位；悬停显示时间范围及所选录音。拼接页使用竖向时间轴，按所有录音的起止边界拆成区间；每个区间直接列出可选片段，显示原片段范围、调性和录制时间，重叠处默认选较新录音。点击候选旁的「试听」只播放它在当前区间的部分，不修改选择；点击候选片段选用后，再「试听整首」或导出。可取消某区间的人声，原文件保持完整。

拼接时间轴中，已选区间旁的「微调」可设置额外人声偏移（±2000 ms）、本段人声音量（0–200%）和接缝淡入／淡出（0–3 秒）。这些设置按“区间＋候选版本”保存，叠加原版本对齐，不影响原始录音及其他区间；更换候选后各自保留，随练习包备份。「试听本段」检查当前区间，「试听前后衔接」包含前后各 2 秒（以导出范围为界）。播放进度与播放器音量集中在弹窗底部，调整后重新试听确认。完整试听和导出复用相同处理：版本对齐与本段偏移、音量和边界淡入淡出 → 拼接 → 全局混响 → 混入伴奏。「重置本段微调」只清除此区间当前候选的调整；「恢复最新」保留微调，仅恢复选片。

满意的录音版本可在「录音」页点击「☆ 标星」，或在拼接候选旁直接点击 ☆。版本列表和拼接候选都会显示 ★；标星录音不受最近版本数限制而自动删除，也随练习包备份迁移。取消标星后恢复普通保留规则，可随时手动删除。选择片段后先切换到要删除的版本，再点击底部标星按钮旁的垃圾桶图标；删除始终针对当前选中的版本。删除标星版本需确认，删除后在底部固定状态栏点击「↶ 撤销删除」可恢复最后删除的版本；仅限本次页面会话，刷新前操作。

练习页和录音页都使用一个回听按钮，右侧下拉箭头可选择「仅回听录音」「先后对比」「同时对比」，两页共用并记住选择，不再单独显示对比按钮。同时对比以录音为时钟，沿用版本的人声对齐、采集偏移和调性，支持暂停与拖动进度。进度条下调原声音量，「回听音量」中调录音人声音量；此模式不额外播放伴奏，原声本身已包含背景。原调直接使用 YouTube；升降调沿用本机服务的原声音轨准备流程。对比快捷键继续可用：选择仅回听时默认执行先后对比，选择同时对比时执行同时对比。

在「录音 → 调整与详情」可为所选独立人声版本设置 ±2000 ms 位移（10 ms 微调），负数提前、正数延后。播放中可直接调整，视频和伴奏位置保持连续；对齐和结尾淡出按版本保存，重置会还原这两项。

「录音 → 声音效果」或「录音设置 → 声音效果」统一设置本视频的 KTV／剧场混响和强度（0–200%），供所有段落、版本回听、混合下载与整首拼接试听／导出共用。整首导出先按各版本的位移拼接人声，再统一加混响并混入伴奏；不会对每段人声单独归一化。导出过载时整体降低音量以保留混音比例，超出导出范围的尾音会裁切。「下载 → 处理后人声 · WAV」包含对齐和统一混响；原始人声下载保持录制时的干声。旧版混合录音不提供独立人声后期。设置随本视频保存并包含在练习包中。旧版按版本保存的混响优先从所选版本迁移为统一设置；其他版本的位移保留。

**实验性耳返混响**：在「麦克风与录音 → 耳机监听」开启耳返和「耳返混响（实验）」，戴有线耳机使用；点击旁边的「调整混响空间与强度」进入统一声音效果设置。默认关闭；录音中可通过实时音量区的「耳返混响（实验）」进入调整，不必停止录音。麦克风试音也使用该设置。混响仅送入耳机监听，不写入录音，直接人声保留原有低延迟通路。不同声卡的实际听感和延迟仍需试听确认。

回放使用**录制时**的起止点与速度，不受之后选中的字幕片段影响。每片段默认保留最近 3 个录音版本，可在「练习设置 → 录音版本保存」设置为 1–100 个，或设为 0 保留全部。此设置对本浏览器所有视频生效，演唱与配音分别计数；调整不会立即删除录音，只在该片段下次保存新录音时清理超限的最旧版本。练习包导入的版本额外保留，可手动删除。展开「录音 → 录音版本」可选择旧版本、下载或删除，并可撤销最近一次删除。

### 可选：电影配音保留背景音

在「对白 · 配音跟读」中，选择当前片段、段落或整段视频，在 **「练习设置 → 录音时的参考音」** 选择 **「背景音（去掉对白）」**。配音默认不播放参考音，按视频记住选择；与唱歌分别保存。

开启后显示「背景音设置」，使用同一套本机 Demucs 服务提取背景音：先点「提取片段／段落／整段背景音」，试听并调整监听音量，再从原来的主按钮开始配音。选择本身不会开始分离或打开麦克风。最长 10 分钟，建议先试短片段；可能残留原对白，也可能损失部分音乐、环境音和音效，暂不支持只去掉一个角色。

录制时只保存麦克风人声；回听可单独开关背景音，并分别调整人声和背景音量。「录音 → 下载与录音详情」可下载原始人声或「人声＋背景音」WAV，混合导出暂支持 1× 录音。改选「不播放」后恢复静音配音，无需运行本机服务；已有带背景音录音仍可在回听区单独控制。电影背景音与歌曲伴奏共用提取、缓存、取消、同步播放和混合导出代码，不需要另外安装服务或模型。电影背景音可在设置中选择 Demucs 或 BandIt，详见上方模型说明。

### 原声与伴奏升降调

在「调整伴奏 → 练习升降调」按半音选择 −6 至 +6，0 为原调。先选调性，再试听或录唱，处理保持节奏与时长。首次切换调性需在浏览器中处理片刻，变调和 WAV 编码均分块执行，可点击停止取消；同一伴奏的最近一次调性会缓存到页面内存。原曲试听、前置原声与录音时的原曲参考音自动跟随同一调性；原声对比使用所选录音版本的调性。0 半音仍直接播放 YouTube，无需服务。非零调性的原声首次播放会通过本机服务提取原声音轨（不去人声、不运行分离模型、无需 GPU），随后复用缓存。请更新并重启本机服务以启用；准备失败时会提示，不会静默播放错误调性。

调性按视频保存，每条录音另记录制时选择的练习调性（包括原曲参考和清唱），回听和混合下载沿用该值。独立人声保持原始音高。旧录音默认原调，练习包保留调性设置。整首或片段合成使用统一调性；所选录音调性不一致时会提示更换版本，避免不同调性直接拼接。合成页的版本列表显示录制时的调性，未选版本和导出范围外的录音不参与检查；人声不会自动变调。变调使用随扩展分发的 SoundTouchJS 0.3.0，第三方许可和适配说明见 `extension/vendor/`。

## 数据与权限

- 仅在 `https://www.youtube.com/*` 注入内容脚本，没有全站读取权限。点词查询使用 Free Dictionary API。
- 麦克风由浏览器按需授权。停止录音后释放麦克风。
- 录音存入 YouTube 页面来源下的 IndexedDB，没有音频上传接口。清理网站数据可能删除录音；它不是扩展独立的私密存储空间。
- 此版本未复制第三方项目代码。架构参考方向来自 DeepHear 与 Shadowing Space。

## 当前限制

- 原型仅支持普通 `/watch?v=...` 视频，暂不支持直播、Shorts、广告中录制。
- 文字记录只读取当前 DOM 已加载的行，不保证完整；YouTube 改版可能影响读取。末句终点可能估算，需手动调整。导入完整字幕更可靠。
- 录音与视频通过两个媒体元素协调播放，尚非逐帧同步。首次播放、卡顿及手动拖动 YouTube 进度条可能引入偏差；练习中请使用面板的停止按钮，避免直接操作播放器。
- 普通配音静音整条视频音轨；可选的本机去原唱功能见 [伴奏安装与使用](karaoke/README.md)。
- 下载的是独立音频，不是合成视频；没有发音评分或云同步；录音版本与历史保存在本机浏览器中。
- 已完成字幕解析自动测试与 JavaScript 语法检查；尚未完成真实 Chrome / YouTube / 麦克风端到端测试。

## 验证

每次提交的快速兼容性检查覆盖 Linux（Python 3.10／3.12）、Windows x64 和 Intel Mac，包括扩展、服务、音频拼接与对应系统启动脚本测试；这些检查不需要下载模型。后端／启动脚本改动另外触发 macOS Intel／Apple 芯片真实模型分离检查，也可手动运行该工作流。托管 runner 不提供可用 GPU 时，MPS 测试会明确报告未验证；自动化测试不代表已验证麦克风、声卡或耳返延迟。

模块职责与媒体流程约定见 [代码结构说明](ARCHITECTURE.md)。开发测试使用 `npm ci` 后运行 `npm test`；fake-indexeddb 仅用于测试数据库迁移、版本保留、删除恢复和会话存储。插件依旧无需安装依赖或构建，直接加载 `extension/`。

运行：

```sh
npm test
node --check extension/content.js
node --check extension/background.js
```

真实浏览器验收：

- 授权 / 拒绝麦克风，取消授权等待后重试。
- 设置 5 秒片段，听原声、配音、自动停止、回放、依次对比。
- 在慢速下配音并回放，确认画面和音频节奏。
- 播放 / 录音时点击停止、关闭面板、切换视频，确认麦克风释放和静音状态恢复。
- 刷新页面恢复最近录音，下载文件确认可播放。
- 分别导入 SRT / VTT，验证多行台词、跳转、隐藏台词。
